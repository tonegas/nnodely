Model Definition
========================
The nnodely framework treats MSNNs as engineering artifacts. It clearly defines their structure, parameters, and dependencies, making architectural choices explicit and reusable.

This apprach lets the user design, compose, validate and deploy neural models in a single consistent workflow, without depending on underlying exectution dependencies.

In this section the user will find the documentation of the main class `Modely` as well as the modules that compose it.
