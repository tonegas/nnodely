Model structured NN Inputs Outputs and Parameters
=================================================

In nnodely, a neural model is built from a few clear, modular components: Inputs, Parameters, Relations, and Outputs. Together, these parts define the model’s structure and how data flows through it. This setup makes design choices clear and makes it easy to build and reuse models based on existing knowledge.
